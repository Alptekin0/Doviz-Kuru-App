# Doviz-Kuru-App

Gerçek zamanlı döviz kuru verilerini FreeCurrencyAPI -> (https://freecurrencyapi.com/) üzerinden çekerek kullanıcıya sunar. Kullanıcılar, seçili bir döviz biriminden diğerlerine anlık dönüşüm yapabilir.



Özellikler:

- Anlık döviz kuru verisi çekme (TRY, USD, EUR, RUB ve diğerleri)
- Gerçek zamanlı kur dönüşümü
- Renkli ve animasyonlu başlık
- Temiz, sade arayüz (HTML, CSS ve JS ile hazırlanmıştır)
